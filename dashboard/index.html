Thought → Action → Observation

Một vòng lặp ReAct diễn ra thế nào

Vòng lặp lặp lại bước 2–4 cho đến khi LLM đủ dữ liệu để trả lời, hoặc chạm giới hạn MAX_ITERATIONS.

1

Nhận câu hỏi

Câu hỏi + System Prompt (7 quy tắc) + danh sách Tool Schema công bố từ MCP Server.

list_tools()
2

Thought

LLM suy luận trên toàn bộ history: cần dữ liệu gì, gọi tool nào, hay đã đủ để trả lời?

generate_with_tools()
3

Action

LLM trả tool_call với tham số trích từ câu hỏi — có thể nhiều tool trong 1 lượt.

call_tool(name, args)
4

Observation

MCP Server trả JSON-RPC 2.0; kết quả được nạp vào history cho lượt suy luận kế tiếp.

history.append(...)
5

Final Answer

LLM trả văn bản khi đã đủ dữ liệu → dừng vòng lặp, ghi trace và phản hồi người dùng.

FINAL_ANSWER
Lõi vòng lặp · src/app.py
while step < max_iterations:
    step += 1
    llm = provider.generate_with_tools(query, tools,
              system_prompt, history=history)   # Thought
    if llm["type"] != "tool_call":
        record(FINAL_ANSWER); break             # Final Answer
    for call in llm["tool_calls"]:              # Action
        obs = mcp_server.call_tool(call["name"],
                                   call["arguments"])["result"]
        record(TOOL_EXECUTION)                  # Observation
    history.append({..., "tool_calls": executed})
else:

Dynamic Decision · Agent phản ứng theo Observation
status từ ToolAgent quyết định
SUCCESSDùng dữ liệu thật để trả lời, hoặc gọi tiếp tool (vd. tra cứu xong → đặt lịch).
SLOT_UNAVAILABLEKhông đặt được giờ đó → đề xuất khung giờ còn trống từ available_slots.
NO_AVAILABLE_SLOTHết lịch trong ngày → gợi ý chọn ngày khác.
NOT_FOUNDSai mã bệnh nhân / chuyên khoa → phản hồi lịch sự, không bịa dữ liệu.
EXECUTION_ERRORTham số sai kiểu → báo lỗi, có thể thử lại với tham số đúng.
UNKNOWN_TOOLTool không tồn tại → không thực thi, tiếp tục suy luận.
